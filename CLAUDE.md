# Vibe Arcade

Load the `arcade` skill (`.claude/skills/arcade/SKILL.md`) before any work in this repo; it explains how the repo works and where every kind of change goes. Goals and non-goals are in `INTENT.md`.

Any change to behaviour or workflow must update the skill and `INTENT.md` in the same commit. Game plans are never tracked (`ideas/` is gitignored). CI commits generated files, so `git pull --rebase` before committing.
